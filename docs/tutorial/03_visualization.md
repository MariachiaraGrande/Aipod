# Module 3 – Data visualization and interpretability

The goal of this module is to provide **visual and interpretative tools** to analyze the behavior of the models trained in the previous step.

Rather than focusing exclusively on prediction accuracy, this module emphasizes **model interpretability and insight**, supporting informed decision-making in the optimization process.

---
## Table of Contents
- [Overview](#overview)

## Overview

The visualization module enables:

- exploratory analysis of model predictions,
- assessment of feature influence on outputs,
- interpretation of multivariate relationships in the design space.

It is designed to work on the **predicted datasets** generated by the model training module.

---

## Step 1 – Definition of visualization data model

The visualization configuration is defined in:

```text
configs/opt_visualization_pydantic.yml
```
This configuration specifies:
* the dataset to be visualized
* input and output variables
* variable types and admissible levels

## Relevant classes
```python
from aipod.models.pydantic_models_visualization import (
    FeatureTypeEnum,
    InputFeature,
    OutputFeature,
    DataModel,
)
```
---
## Dataset specification
* `dataframe: str` dataframe path
---
## Input variables(`InputFeature`)
Each input feature is defined through:
* `feature_name:str` 
* `id: str`  
* `value_list: list` Discrete levels used for visualization
* `value_type: FeatureTypeEnum` Variable type (`Float`, `Cat`, `OrdCat`)
* `feature_description: str` 

---
## Ouput variables (`OuputFeature`)
Each output variable include:
* `feature_name:str` 
* `id: str`  
* `value_type: FeatureTypeEnum` 
* `feature_description: str` 
---
## Application example
```python
file = "../docs/data_processed/predicted_df.xlsx"

input0 = InputFeature(
    feature_name="A",
    id="id_0",
    value_list=[50, 75, 100],
    value_type=FeatureTypeEnum("OrdCat"),
)

input1 = InputFeature(
    feature_name="B",
    id="id_2",
    value_list=[240, 3880, 8000],
    value_type=FeatureTypeEnum("OrdCat"),
)

input2 = InputFeature(
    feature_name="C",
    id="id_3",
    value_list=[30, 50, 70, 90, 110],
    value_type=FeatureTypeEnum("OrdCat"),
)

output0 = OutputFeature(
    feature_name="out1",
    id="out_0",
    value_type=FeatureTypeEnum("Float"),
    feature_description="out1_description",
)

output1 = OutputFeature(
    feature_name="out2",
    id="out_1",
    value_type=FeatureTypeEnum("Float"),
    feature_description="out2_description",
)

datamodel = DataModel(
    dataframe=file,
    input_vars=[input0, input1, input2],
    output_vars=[output0, output1],
)
```

## Step 2: Visualization and interpretability tools

To generate visualization, the `Visualization` handler must be inizialized

```python
from aipod.optimization.handler_visualization import Visualization
graph = Visualization(data=datamodel)
```
___
## Scatter and conditional plots
Scatter plots allow the inspection of relationships between variables and outputs under different conditions.

```python
graph.scatter_plot(
    x="C",
    y=["out1", "out1_pred"],
    col="A",
    row="B",
    orders={"A": [50, 75, 100], "B": [240, 3880, 8000]},
    title="Design optimization"
)
```
---
## SHAP-based analysis

SHAP (SHapley Additive exPlanations) analysis is used to quantify the contribution of each input variable to the model predictions.
```python
from sklearn.ensemble import RandomForestRegressor

graph.SHAP_analysis(
    target="out1",
    estimator=RandomForestRegressor(n_estimators=100, random_state=42),
)

shap_values_target_1 = graph.shap_values
graph.biplot_centroids()
features_target_1 = graph.features_target1
```

The procedure can be repeated for multiple output targets

---

## Biplot-like visualization 
Biplot-like graph provide a compact representation of multivariate relationships, combining:
* SHAP values
* feature centroids
* multiple output targets

```python
graph.biplot_features(
    shap_values_target_1=shap_values_target_1,
    shap_values_target_2=shap_values_target_2,
    features_target1=features_target_1,
    features_target2=features_target_2,
    title="Biplot-like analysis",
    colors_x=["b", "m", "green"],
    colors_points=["c", "violet", "y"],
)
```

This visualization support:
* comparative analysis betwwen objectives
* identification of dominant variables
* insight into trade-offs in the design space
